p5.mbt examples

Build them first with moon build --target js --release, then serve the repository root.

  • shapes — primitives, curves, contours, HSB colors, transforms, text
  • images — loading, filters, tint, pixels, graphics buffers
  • flowfield — vectors, Perlin noise, DOM sliders and buttons
  • input — keyboard, mouse, wheel, clipping, erasing
  • data — loading JSON and text files in preload
  • dom — video as pixels, radio buttons, file input, dropping files
  • orrery — WEBGL: lights, emissive and specular materials, generated textures, labels drawn with the font shader, orbit control
  • terrain — WEBGL: noise terrain from triangle strips with vertex colors, fog added to p5's material shader with a hook
  • feedback — WEBGL: framebuffer feedback trails
  • particles — text_to_points: a word made of springy particles
